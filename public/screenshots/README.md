# Project screenshots

Drop app screenshots here (PNG/JPG/WebP, ideally ~800×600 or a phone-frame
mockup on a clean background), then point the project at it in
`src/data/portfolio.js`:

```js
{
  name: "Spendable",
  ...
  image: "screenshots/spendable.png",
}
```

Until an `image` is set, each project card shows a branded placeholder, so
missing screenshots never break the layout.

Tip: free device-frame mockup tools — https://mockuphone.com or
https://screenshots.pro — make store screenshots look great here.
